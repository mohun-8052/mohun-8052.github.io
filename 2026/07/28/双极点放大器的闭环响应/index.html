两极点的位置（即s的解）与$A_0\beta$相关。由于$A_0$不变，因此不同的反馈系数$\beta$会使得闭环极点的位置不同：

  • 随着$\beta$由0（$\beta=0$即开环）不断增大，闭环极点逐步相互靠近。
  • 当$\beta$达到一定数值时，两极点重合。
  • 当$\beta$继续增大，其极点将成为一对共轭极点并沿着一条垂直线移动。

显然，当$\beta$最大时，反馈闭环电路的稳定性最差。

$\omega_n$大小不受零点影响！！

$\zeta$大小受零点影响！！

是的，阻尼比 (\zeta) 与共轭极点位置有直接且重要的几何关系。

1. 极点的极坐标表示

二阶系统的共轭极点为：
[
s_{1,2} = -\zeta\omega_n \pm j\omega_n\sqrt{1-\zeta^2} = -\sigma \pm j\omega_d
]
极点在 (s) 平面上的极径（到原点的距离）正是无阻尼自然频率：
[
r = |s_{1,2}| = \omega_n
]
极角 (\theta) 是极点向量与负实轴的夹角，满足：
[
\cos\theta = \frac{\sigma}{r} = \frac{\zeta\omega_n}{\omega_n} = \zeta
]
即
[
\boxed{\zeta = \cos\theta}
]
因此，阻尼比 (\zeta) 直接决定了共轭极点在 (s) 平面上的角度位置：

  • 每一个 (\zeta) 对应一条从原点出发、与负实轴夹角为 (\theta = \arccos\zeta) 的射线，极点只能位于这条等 (\zeta) 线上。
  • (\zeta) 不变时，(\omega_n) 变化只会让极点沿这条射线径向移动。

2. 本电路的体现

由前推导：
[
\zeta = \frac{\omega_{p1}+\omega_{p2}}{2\sqrt{\omega_{p1}\omega_{p2}(1+A_0\beta)}}
]
随着 (\beta) 增大：

  • (\zeta) 从 (>1) 下降到 (<1)，极点从负实轴分离为一对共轭复极点。
  • 当 (\beta > \beta_c) 后，(\sigma = \frac{\omega_{p1}+\omega_{p2}}{2}) 恒定，(\omega_d = \omega_n\sqrt{1-\zeta^2} = \sqrt{\omega_n^2 - \sigma^2}) 随 (\beta) 增大，极点上移。此时：
    [
    \zeta = \frac{\sigma}{\omega_n} = \frac{\sigma}{\sqrt{\sigma^2 + \omega_d^2}}
    ]
    虚部 (\omega_d) 增大 ⇒ (\zeta) 减小 ⇒ 极角 (\theta = \arccos\zeta) 增大 ⇒ 极点更靠近虚轴，超调增加，稳定性相对变差。

3. (\zeta) 与极点位置关系的总结

(\zeta) 值 极点位置 物理意义
(\zeta > 1) 两个不等负实根，均在负实轴上 过阻尼，无振荡
(\zeta = 1) 二重负实根 临界阻尼
(0<\zeta<1) 共轭复极点，位于与负实轴夹角 (\arccos\zeta) 的射线上 欠阻尼，衰减振荡
(\zeta = 0) 共轭纯虚根 ±jω_n 无阻尼等幅振荡
(\zeta < 0) 极点进入右半平面 不稳定，发散振荡

因此，阻尼比不仅与极点位置有关，它本身就是对该位置的一种几何描述——共轭极点所在射线与负实轴夹角的余弦。

1. 对阻尼比的直接影响

将方程写成标准二阶形式 (s^2 + 2\zeta\omega_n s + \omega_n^2 = 0)：
[
\omega_n = \sqrt{\omega_{p1}\omega_{p2}(1+\beta A_0)}, \quad
\zeta = \frac{a_1}{2\omega_n} = \frac{\omega_{p1}+\omega_{p2}}{2\omega_n} + \frac{\beta A_0\,\omega_{p1}\omega_{p2}}{2\omega_n\,\omega_z}
]
(\zeta) 表达式中的第二项 随 (\omega_z) 减小而增大。因此：

  • 当 (\omega_z \to \infty)（无零点）：(\zeta = \frac{\omega_{p1}+\omega_{p2}}{2\omega_n})，系统可能因低阻尼而出现强烈振荡。
  • 当 (\omega_z) 向低频移动（零点靠近原点）：(\zeta) 单调增大，系统阻尼增强。当 (\zeta \ge 1) 时，闭环极点变为两个负实根，系统由欠阻尼过渡到过阻尼，超调消失，响应变慢但更平稳。
  • 若 (\omega_z) 为正但极小：(a_1) 非常大，一个极点会趋近 (-\omega_z)（被零点“吸引”），另一个极点趋近 (-\frac{a_0}{\omega_z}) 而变得非常负，系统呈现一阶主导特性。

2. 从根轨迹看 (\omega_z) 的作用

开环极点位于 (-\omega_{p1})、(-\omega_{p2})，零点位于 (-\omega_z)（假设均在左半平面）。根轨迹法则指出：零点会吸引根轨迹，使闭环极点向零点方向移动。

  • 零点位于极点左侧（(\omega_z > \omega_{p2})）：根轨迹向左弯曲，两个分支先在实轴上分离（或汇合），然后可能沿渐近线进入左半平面。零点使分离角减小，系统更容易稳定。
  • 零点位于两极之间（(\omega_{p1} < \omega_z < \omega_{p2})）或极点右侧（(\omega_z < \omega_{p1})）：零点将位于实轴上的一个极点“拉”向自己，该分支沿实轴向左移动，成为主导极点；另一分支则远离虚轴向左移动。此时系统阻尼显著增加，甚至变成两个一阶环节。

无论哪种情况，左半平面零点都提供正相位（相位超前），增大了相位裕度，使闭环极点向左偏移，相对稳定性提高。

3. 定量影响：偏导数分析

固定其他参数，(a_1) 对 (1/\omega_z) 的敏感度为：
[
\frac{\partial a_1}{\partial (1/\omega_z)} = \beta A_0\,\omega_{p1}\omega_{p2} > 0
]
可见 (\omega_z) 下降（(1/\omega_z) 上升）直接使 (a_1) 线性增大。由于 (\omega_n) 恒定，阻尼比 (\zeta) 以相同趋势增大。闭环极点实部绝对值增大（极点向左移动），虚部减小（振荡减弱）。

4. 特殊情况下的极点近似

  • (\omega_z \to \infty)（无零点）：(s) 退化为原无零点方程的解，可能为共轭复根。
  • (\omega_z) 使 (a_1^2 = 4a_0)（临界阻尼点）：解得
    [
    \omega_z = \frac{\beta A_0\,\omega_{p1}\omega_{p2}}{2\sqrt{\omega_{p1}\omega_{p2}(1+\beta A_0)} - (\omega_{p1}+\omega_{p2})}
    ]
    此时两闭环极点重合为负实数。
  • (\omega_z \to 0^+)（零点极度接近原点）：一个极点 (p_1 \to -\omega_z)，另一个 (p_2 \to -\infty)（快速衰减），系统近似为一阶系统，时间常数 (1/\omega_z)。

总结

零点 (-\omega_z) 是改善稳定性和抑制振荡的关键手段：

  • 减小 (\omega_z)（零点向低频移动）→ 阻尼比增大 → 振荡减小、超调降低，但响应速度可能变慢；
  • 增大 (\omega_z)（零点远离原点）→ 影响减弱，系统趋近于原始双极点响应的欠阻尼状态。

在实际设计中，可调节 (\omega_z) 来同时满足快速性和稳定性的折中要求。
